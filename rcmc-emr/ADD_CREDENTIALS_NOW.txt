========================================
  ADD GOOGLE CREDENTIALS FILE
========================================

SUPER SIMPLE - JUST COPY A FILE!


STEP 1: Find the File
----------------------
Look in your Downloads folder for a file like:
- rcmc-lab-results-xxxxx.json
- project-name-xxxxx.json

This is the file you downloaded from Google Cloud Console.


STEP 2: Copy the File
---------------------
Right-click the file → Copy (or Ctrl+C)


STEP 3: Go to Server Folder
----------------------------
Open File Explorer and go to:
C:\Users\ralfh\Desktop\Kiro\rcmc-emr\server


STEP 4: Paste the File
----------------------
Right-click in the folder → Paste (or Ctrl+V)


STEP 5: Rename (if needed)
--------------------------
Rename the file to exactly:
google-credentials.json


DONE!
-----
Your server folder should now have:
- google-credentials.json  ← NEW!
- .env
- index.js
- package.json


THEN: Start Backend
-------------------
Double-click: START_BACKEND.bat
