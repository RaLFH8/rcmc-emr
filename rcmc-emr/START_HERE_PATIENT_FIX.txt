PROBLEM:
--------
Patients were not appearing in the Patients module after booking appointments.

ROOT CAUSE:
-----------
Manual booking in Appointments page only allowed SELECTING existing patients.
It didn't CREATE new patients.

SOLUTION:
---------
Added "Quick Add Patient" button to Appointments modal!
Now you can create new patients directly when scheduling appointments.

HOW TO USE:
-----------

METHOD 1: Select Existing Patient (Same as before)
  1. Go to Appointments
  2. Click "New Appointment"
  3. Select patient from dropdown
  4. Fill appointment details
  5. Submit

METHOD 2: Add New Patient (NEW!)
  1. Go to Appointments
  2. Click "New Appointment"
  3. Click "+ Add New Patient" button  ← NEW!
  4. Fill patient information form
  5. Fill appointment details
  6. Submit
  7. ✅ Patient appears in Patients module immediately!
