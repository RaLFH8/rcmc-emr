  TEXTBEE SMS GATEWAY - QUICK START (5 MINUTES)
═══════════════════════════════════════════════════════════

✅ TEXTBEE IS NOW CONFIGURED IN YOUR CODE!

📱 STEP 1: INSTALL TEXTBEE (2 minutes)
   1. Open Play Store on your Android phone
   2. Search "TextBee SMS Gateway"
   3. Install and open the app
   4. Grant SMS permissions when asked

🔧 STEP 2: CONFIGURE TEXTBEE (2 minutes)
   1. Enable "HTTP Server" toggle in the app
   2. Note the IP address shown (e.g., 192.168.1.100:5000)
   3. Set an API key (optional, e.g., "rcmc2026")

📝 STEP 3: UPDATE .ENV FILE (1 minute)
   Open: rcmc-emr/.env
   
   Update these lines:
   VITE_TEXTBEE_URL=http://192.168.1.100:5000
   VITE_TEXTBEE_API_KEY=rcmc2026
   
   (Replace with YOUR phone's IP and API key)

🚀 STEP 4: RESTART & TEST
   1. Stop dev server (Ctrl+C)
   2. Run: npm run dev
   3. Create test appointment with your number
   4. Check if SMS received!
