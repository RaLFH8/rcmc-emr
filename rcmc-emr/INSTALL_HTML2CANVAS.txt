INSTALL HTML2CANVAS FOR PDF DOWNLOAD
=====================================

The prescription PDF download feature requires html2canvas library.

STEP 1: Install the package
----------------------------
Open your terminal in the rcmc-emr folder and run:

npm install html2canvas

OR if you prefer yarn:

yarn add html2canvas


STEP 2: Restart the development server
---------------------------------------
After installation, restart your dev server:

1. Stop the current server (Ctrl+C)
2. Run: npm run dev
3. Open http://localhost:3002


WHAT WAS CHANGED:
-----------------
✅ Added html2canvas to package.json dependencies
✅ Updated Prescriptions.jsx to use html2canvas for PDF generation
✅ Download button now generates actual PDF files instead of opening print dialog

HOW IT WORKS:
-------------
- Print button: Opens browser print dialog
- Download button: Captures prescription as image and generates PDF file
- PDF filename format: Prescription_PatientName_Date.pdf
- PDF size: A5 (148mm x 210mm)

After installing html2canvas, the download feature will work properly!
