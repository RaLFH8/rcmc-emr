───────────────────────────────────────────────────────────────────
  OPTION 1: EMAIL ONLY (FASTEST - 10 MIN) ⭐ RECOMMENDED
───────────────────────────────────────────────────────────────────

1. Sign up: https://resend.com (FREE)
2. Get API key from dashboard
3. Add to .env:
   VITE_RESEND_API_KEY=re_xxxxxxxxxxxxx
   VITE_FROM_EMAIL=RCMC Clinic <onboarding@resend.dev>
4. Restart: npm run dev
5. Done! ✅

Cost: FREE (100 emails/day, 3,000/month)
Guide: RESEND_EMAIL_SETUP_GUIDE.md

───────────────────────────────────────────────────────────────────
  OPTION 2: SMS ONLY (30 MIN)
───────────────────────────────────────────────────────────────────

1. Install: "SMS Gateway for Android" (Play Store)
2. Get: API Key + Device ID from app
3. Add to .env:
   VITE_SMS_GATEWAY_API_KEY=your_key
   VITE_SMS_GATEWAY_DEVICE_ID=your_id
4. Restart: npm run dev
5. Done! ✅

Cost: ₱300-500/month (your SIM load)
Guide: SMS_WITH_PHILIPPINE_SIM_GUIDE.md

───────────────────────────────────────────────────────────────────
  OPTION 3: BOTH EMAIL + SMS (BEST - 40 MIN) ⭐⭐⭐
───────────────────────────────────────────────────────────────────

1. Do Option 1 (Email)
2. Do Option 2 (SMS)
3. Both work automatically! ✅

Cost: FREE + ₱300-500/month
Benefit: Redundancy - if one fails, other works!
