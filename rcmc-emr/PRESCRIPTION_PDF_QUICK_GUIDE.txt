┌──────────────────────────────────────────────────────────────┐
│ 🎯 HOW TO SAVE AS PDF                                        │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│ METHOD 1: From Prescription List                            │
│   1. Go to Prescriptions page                                │
│   2. Find the prescription                                   │
│   3. Click Download icon (blue button)                       │
│   4. Select "Save as PDF" in print dialog                    │
│   5. Click Save                                              │
│                                                              │
│ METHOD 2: From Edit Modal                                    │
│   1. Click Edit on prescription                              │
│   2. Click "Save PDF" button (blue)                          │
│   3. Select "Save as PDF" in print dialog                    │
│   4. Click Save                                              │
│                                                              │

├──────────────────────────────────────────────────────────────┤
│                                                              │
│ PRINT BUTTON (Printer Icon - Gray)                          │
│   • Sends to printer                                         │
│   • For physical copies                                      │
│   • Same format as PDF                                       │
│                                                              │
│ SAVE PDF BUTTON (Download Icon - Blue)                      │
│   • Opens print dialog                                       │
│   • Select "Save as PDF"                                     │
│   • Creates digital copy                                     │
│   • Can email or store                                       │
│                                                              │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 💡 TIPS                                                      │
├──────────────────────────────────────────────────────────────┤
│ • Paper Size: A5 (prescription pad size)                     │
│ • Margins: 10mm (already set)                                │
│ • Scale: 100% (default)                                      │
│ • Color: Works in color or B&W                               │
│                                                              │
│ File Naming:                                                 │
│   Rx_PatientName_Date.pdf                                    │
│   Example: Rx_JohnDoe_2024-02-22.pdf                         │
│                                                              │
│ Keyboard Shortcut:                                           │
│   Ctrl+P (Windows) or Cmd+P (Mac)                            │
│   Then select "Save as PDF"                                  │
