📱 WHAT YOU NEED TO DO (10 Minutes):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Install HTTP SMS App (3 minutes)
────────────────────────────────────────
1. Open Play Store on your Android phone
2. Search "HTTP SMS"
3. Install the app
4. Open app and grant SMS permissions


STEP 2: Configure HTTP SMS App (3 minutes)
────────────────────────────────────────
1. In the app, enable "HTTP Server" (toggle ON)
2. Note the IP address shown (e.g., 192.168.1.100:8080)
3. Set a password (optional but recommended)
4. Keep the app running


STEP 3: Update .env File (2 minutes)
────────────────────────────────────────
1. Open file: rcmc-emr/.env
2. Find these lines:
   
   VITE_HTTP_SMS_URL=http://192.168.1.100:8080
   VITE_HTTP_SMS_PASSWORD=

3. Replace with YOUR phone's IP and password:
   
   VITE_HTTP_SMS_URL=http://[YOUR_PHONE_IP]:[PORT]
   VITE_HTTP_SMS_PASSWORD=[YOUR_PASSWORD]

4. Save the file


STEP 4: Restart Dev Server (1 minute)
────────────────────────────────────────
1. Stop current server (press Ctrl+C)
2. Start again: npm run dev


STEP 5: Test SMS (1 minute)
────────────────────────────────────────
1. Login to RCMC EMR
2. Go to Appointments page
3. Create test appointment with YOUR mobile number
4. Check if you receive SMS
5. Verify in HTTP SMS app logs
