QUESTION 2: Does the time get locked if already booked or the time 
            has passed?

✅ YES - BOTH ARE LOCKED!

PART A: ALREADY BOOKED TIMES ✅
├─ System checks existing appointments
├─ Marks booked times as unavailable
├─ Only shows available slots
└─ Prevents double booking

EXAMPLE:
┌────────────────────────────────────────────────────────────────────┐
│ Dr. Smith - Tomorrow - 10:00 AM                                    │
│                                                                    │
│ Booking 1: Juan books 10:00 AM ✅                                  │
│ → Appointment created                                             │
│                                                                    │
│ Booking 2: Maria tries to book 10:00 AM                           │
│ → 10:00 AM NOT shown (already booked)                             │
│ → Can only see: 10:20 AM, 10:40 AM, 11:00 AM, etc.               │
└────────────────────────────────────────────────────────────────────┘

PART B: PAST TIME SLOTS ✅
├─ For TODAY: Filters out past times
├─ Adds 20-minute buffer
├─ Only shows future slots
└─ Prevents booking in the past

EXAMPLE:
┌────────────────────────────────────────────────────────────────────┐
│ Current Time: 2:00 PM                                              │
│ Selected Date: TODAY                                               │
│                                                                    │
│ Available Slots:                                                   │
│ ❌ 10:00 AM (past)                                                 │
│ ❌ 12:00 PM (past)                                                 │
│ ❌ 2:00 PM (past + buffer)                                         │
│ ✅ 2:20 PM (available)                                             │
│ ✅ 2:40 PM (available)                                             │
│ ✅ 3:00 PM (available)                                             │
└────────────────────────────────────────────────────────────────────┘

RESULT: ✅ Booked slots locked, past times locked
