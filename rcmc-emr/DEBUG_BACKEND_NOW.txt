🐛 COMMON ISSUES:

1. Backend not running
   → Double click START_BOTH_SERVERS.bat

2. Wrong port
   → Backend must be on 3003
   → Frontend must be on 3002

3. Firewall blocking
   → Allow Node.js in Windows Firewall

4. Another app using port 3003
   → Close other apps
   → Or change port in server/.env
