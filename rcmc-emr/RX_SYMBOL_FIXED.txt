✅ RX SYMBOL FIXED IN PDF
===========================

PROBLEM:
--------
The Unicode ℞ character wasn't rendering properly in jsPDF.

SOLUTION:
---------
Created a custom-drawn Rx symbol using basic shapes:

1. Large "R" (56pt Times Bold)
2. Subscript "x" (32pt Times Bold)
3. Diagonal line through the R leg

This creates the proper medical prescription Rx symbol (℞).

HOW IT WORKS:
-------------
┌─────────────┐
│    R        │  ← Large R (56pt)
│   /│        │  ← Diagonal line
│  / │        │
│    x        │  ← Subscript x (32pt)
└─────────────┘

VISUAL RESULT:
--------------
    R
   /│
  / │
    x

This matches the standard medical prescription Rx symbol.

TECHNICAL DETAILS:
------------------
- R position: margin + 3, yPos
- R size: 56pt Times Bold
- x position: margin + 14, yPos + 3
- x size: 32pt Times Bold
- Diagonal line: from (margin + 11, yPos - 8) to (margin + 18, yPos + 4)
- Line width: 1.5mm
- Color: slate-900 (#0f172a)

TESTING:
--------
1. Open Prescriptions page
2. Create or view a prescription
3. Click "Download" button
4. Check PDF shows proper Rx symbol with diagonal line
