========================================
🚀 HOW TO START THE DEVELOPMENT SERVER
========================================

Your RCMC-EMR is ready to run locally!

========================================
METHOD 1: DOUBLE-CLICK (EASIEST)
========================================

1. Go to the rcmc-emr folder
2. Double-click: START_SERVER_NOW.bat
3. Wait for server to start (10-15 seconds)
4. Browser will open automatically at:
   http://localhost:3001

========================================
METHOD 2: COMMAND PROMPT
========================================

1. Open Command Prompt (cmd)

2. Navigate to project:
   cd C:\Users\ralfh\Desktop\Kiro\rcmc-emr

3. Start server:
   npm run dev

4. Wait for this message:
   "Local: http://localhost:3001/"

5. Open browser and go to:
   http://localhost:3001

========================================

Press: Ctrl + C

Or just close the Command Prompt window

========================================
TROUBLESHOOTING:
========================================

Error: "npm: command not found"
→ Install Node.js from: https://nodejs.org/

Error: "Cannot find module"
→ Run: npm install
→ Then: npm run dev

Error: "Port 3001 already in use"
→ Close other instances
→ Or change port in vite.config.js

Error: "VITE_SUPABASE_URL is not defined"
→ Check .env file exists
→ Should contain Supabase credentials
