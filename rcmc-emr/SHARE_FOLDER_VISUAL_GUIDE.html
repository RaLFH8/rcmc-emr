🎯 Share Google Drive Folder with Service Account

⚠️ IMPORTANT: The error you're seeing means the folder is NOT shared with the service account yet. Follow these steps exactly.

Step 1: Copy the Service Account Email

This is the email address that needs access to your Google Drive folder:

rcmc-lab-uploader@rcmc-lab-results.iam.gserviceaccount.com

Step 2: Open Google Drive

  1. Go to Google Drive
  2. Make sure you're logged into the correct Google account

Step 3: Find Your Folder

Option A: Search by Folder ID

  1. In Google Drive search bar, paste this folder ID:
    2. 1JBKtpUdImoQc1LPzyrmVpOsUCYeTky64
  2. Press Enter to search

Option B: Find by Name

  1. Look for a folder named "Lab Results" or "RCMC Lab Results"
  2. If you can't find it, you may need to create a new one (see Step 6 below)

Step 4: Share the Folder

  1. Right-click on the folder
  2. Click "Share" from the menu
  3. In the "Add people and groups" field, paste the service account email
  4. Make sure permission is set to "Editor" (not Viewer)
  5. Click "Send"
  6. IGNORE any warning about "This user may not be notified" - that's normal for service accounts

Step 5: Test Upload

  1. Go back to http://localhost:3001
  2. Click "Lab Results" in the sidebar
  3. Click "Upload Lab Result"
  4. Select a patient and upload a PDF
  5. IT WILL WORK! 🎉

❓ Can't Find the Folder?

If you can't find the folder with ID 1JBKtpUdImoQc1LPzyrmVpOsUCYeTky64, create a new one:

Step 6: Create New Folder (Alternative)

  1. In Google Drive, click "New" → "Folder"
  2. Name it: "RCMC Lab Results"
  3. Right-click the new folder → "Share"
  4. Paste the service account email (use Copy button above)
  5. Set permission to "Editor"
  6. Click "Send"
  7. Open the folder and look at the URL
  8. Copy the folder ID from the URL (the long string after /folders/)
  9. Update rcmc-emr/server/.env file with the new folder ID
  10. Restart the backend server

✅ How to Know It Worked

After sharing the folder, when you try to upload a lab result:

  • You'll see "Lab result uploaded successfully!"
  • The file will appear in your Google Drive folder
  • The lab result will show in the Lab Results page

🔍 Still Not Working?

Check these common issues:

  • Did you click "Send" after adding the email?
  • Did you set permission to "Editor" (not "Viewer")?
  • Are you logged into the correct Google account?
  • Is the backend server still running?
