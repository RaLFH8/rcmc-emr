═══════════════════════════════════════════════════════════════════
  WHAT YOU NEED TO DO (10 MINUTES)
═══════════════════════════════════════════════════════════════════

📱 STEP 1: Install HTTP SMS App (3 minutes)
   1. Open Play Store on Android phone
   2. Search "HTTP SMS"
   3. Install and open app
   4. Grant SMS permissions

🔧 STEP 2: Configure App (3 minutes)
   1. Enable "HTTP Server" toggle
   2. Note IP address (e.g., 192.168.1.100:8080)
   3. Set password (optional)
   4. Keep app running

📝 STEP 3: Update .env File (2 minutes)
   1. Open: rcmc-emr/.env
   2. Update:
      VITE_HTTP_SMS_URL=http://[YOUR_IP]:[PORT]
      VITE_HTTP_SMS_PASSWORD=[YOUR_PASSWORD]
   3. Save file

🚀 STEP 4: Restart Server (1 minute)
   Ctrl+C to stop, then: npm run dev

✅ STEP 5: Test (1 minute)
   Create appointment with your number, check SMS

  TROUBLESHOOTING QUICK REFERENCE
═══════════════════════════════════════════════════════════════════

Problem: "Connection refused"
→ Check: Same WiFi? Server enabled? Correct IP?

Problem: "SMS failed"
→ Check: Permission granted? Have load? SIM working?

Problem: IP keeps changing
→ Solution: Set static IP on phone

Problem: Phone goes to sleep
→ Solution: Disable battery optimization

Problem: Can't find app
→ Solution: Try alternative apps or SMS.to

For detailed solutions: SMS_TROUBLESHOOTING.md
