🔧 FIX: New Users Can't Sign In
==================================

PROBLEM:
--------
Doctor and receptionist users created in Supabase Dashboard can't log in.

WHY:
----
When you create users in Supabase Dashboard, it only creates the AUTH account.
The EMR system also needs a USER PROFILE in the user_profiles table.

SOLUTION - QUICK FIX:
---------------------

1. Go to Supabase Dashboard
2. Click "SQL Editor" in the left menu
3. Click "New Query"
4. Copy and paste this SQL (REPLACE THE VALUES):

```sql
-- Get the user IDs first
SELECT id, email FROM auth.users ORDER BY created_at DESC LIMIT 5;
```

5. Copy the UUID (id) for each new user
6. Then run this for EACH new user:

```sql
-- For Doctor user:
INSERT INTO public.user_profiles (id, email, full_name, role, status, created_at)
VALUES (
  'PASTE_UUID_HERE',      -- UUID from step 5
  'doctor@rcmc.com',      -- Their email
  'Dr. John Doe',         -- Their name
  'doctor',               -- Their role
  'Active',
  NOW()
);

-- For Receptionist user:
INSERT INTO public.user_profiles (id, email, full_name, role, status, created_at)
VALUES (
  'PASTE_UUID_HERE',      -- UUID from step 5
  'receptionist@rcmc.com', -- Their email
  'Jane Smith',           -- Their name
  'receptionist',         -- Their role
  'Active',
  NOW()
);
```

7. Click "Run" button
8. Users can now log in!

EXAMPLE WITH REAL DATA:
-----------------------
If your doctor user has:
- UUID: a1b2c3d4-e5f6-7890-abcd-ef1234567890
- Email: drjohn@rcmc.com
- Name: Dr. John Santos

Run this:
```sql
INSERT INTO public.user_profiles (id, email, full_name, role, status, created_at)
VALUES (
  'a1b2c3d4-e5f6-7890-abcd-ef1234567890',
  'drjohn@rcmc.com',
  'Dr. John Santos',
  'doctor',
  'Active',
  NOW()
);
```

AVAILABLE ROLES:
----------------
- 'admin' - Full access
- 'doctor' - Access to patients, consultations, prescriptions
- 'nurse' - Access to patients, appointments, inpatients
- 'receptionist' - Access to appointments, patients, billing

VERIFY IT WORKED:
-----------------
Run this to check:
```sql
SELECT 
  up.email,
  up.full_name,
  up.role,
  up.status
FROM user_profiles up
ORDER BY up.created_at DESC;
```

You should see all your users listed!

AFTER LOGIN:
------------
If the user is a doctor:
1. Log in as admin
2. Go to User Management
3. Click "Edit" on the doctor user
4. Select which doctor profile to link
5. Save

Now the doctor user is fully set up!
