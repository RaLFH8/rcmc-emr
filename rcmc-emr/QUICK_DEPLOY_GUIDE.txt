┌──────────────────────────────────────────────────────────────┐
│  STEP 1: BUILD YOUR PROJECT (1 minute)                       │
└──────────────────────────────────────────────────────────────┘

  Open Command Prompt in rcmc-emr folder and run:
  
  npm run build
  
  ✓ This creates a 'dist' folder with production files


┌──────────────────────────────────────────────────────────────┐
│  STEP 2: PUSH TO GITHUB (2 minutes)                          │
└──────────────────────────────────────────────────────────────┘

  Option A - GitHub Desktop (Easiest):
  1. Download: https://desktop.github.com/
  2. Open GitHub Desktop
  3. Add Local Repository → Select rcmc-emr folder
  4. Publish Repository → Name: rcmc-emr → Private
  
  Option B - Command Line:
  git init
  git add .
  git commit -m "Deploy RCMC-EMR"
  git remote add origin https://github.com/YOUR_USERNAME/rcmc-emr.git
  git push -u origin main


┌──────────────────────────────────────────────────────────────┐
│  STEP 3: DEPLOY TO CLOUDFLARE (2 minutes)                    │
└──────────────────────────────────────────────────────────────┘

  1. Visit: https://dash.cloudflare.com/
  2. Click: Pages → Create a project
  3. Connect to Git → Select rcmc-emr repository
  4. Configure:
     - Build command: npm run build
     - Build output: dist
     - Framework: Vite
  5. Add Environment Variables:
     - VITE_SUPABASE_URL = https://imznlhualfuvstfyvdns.supabase.co
     - VITE_SUPABASE_ANON_KEY = eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
  6. Click: Save and Deploy
  
  ✓ Wait 2-3 minutes for deployment to complete


┌──────────────────────────────────────────────────────────────┐
│  STEP 4: UPDATE SUPABASE (1 minute)                          │
└──────────────────────────────────────────────────────────────┘

  1. Go to: https://supabase.com/dashboard
  2. Select your project
  3. Settings → Authentication → URL Configuration
  4. Add your Cloudflare URL:
     - Site URL: https://rcmc-emr.pages.dev
     - Redirect URLs: https://rcmc-emr.pages.dev/**
