========================================
RCMC-EMR - QUICK DEPLOY TO CLOUDFLARE
========================================

STEP 1: BUILD (2 minutes)
--------------------------
Double-click: BUILD_AND_DEPLOY.bat

OR run in Command Prompt:
  cd rcmc-emr
  npm run build

Wait for "dist" folder to be created.

STEP 2: UPLOAD TO CLOUDFLARE (3 minutes)
-----------------------------------------
1. Go to: https://dash.cloudflare.com/
2. Click: Pages
3. Find: RCMC-EMR project
4. Click: Create deployment
5. Drag: The "dist" folder
6. Click: Save and Deploy
7. Wait: 1-2 minutes
8. Click: Visit site

TROUBLESHOOTING:
----------------
Build fails?
  → Run: npm install
  → Then: npm run build

Upload fails?
  → Zip the dist folder first
  → Upload the zip file

Data not saving?
  → Run ULTIMATE_FIX_EVERYTHING.sql in Supabase first
