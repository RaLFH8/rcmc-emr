✅ CONSULTATION DISPLAY IN PATIENTS PAGE - FIXED!

## What Was Fixed

The Patients page was showing hardcoded consultation data instead of real consultations from the database.

## Changes Made

### 1. Added State Management
```javascript
const [consultations, setConsultations] = useState([])
const [loadingConsultations, setLoadingConsultations] = useState(false)
```

### 2. Updated handleViewHistory Function
Now loads real consultations when viewing a patient:
```javascript
const handleViewHistory = async (patient) => {
  setViewingPatient(patient)
  setShowHistoryModal(true)
  
  // Load consultations for this patient
  setLoadingConsultations(true)
  try {
    const consultationsData = await db.getConsultations(patient.id)
    setConsultations(consultationsData || [])
  } catch (error) {
    console.error('Error loading consultations:', error)
    setConsultations([])
  } finally {
    setLoadingConsultations(false)
  }
}
```

### 3. Replaced Hardcoded Consultations Section
Now displays real SOAP notes from database:
- Shows all consultations for the patient
- Displays complete SOAP format (S.O.A.P)
- Shows correct doctor name
- Shows consultation date/time
- Expandable full notes section
- Shows total consultation count
