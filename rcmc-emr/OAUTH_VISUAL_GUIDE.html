🔐 Google OAuth Setup

Lab Results Upload for RCMC EMR

⏱️ Time Required: 5-10 minutes
💰 Cost: Free (uses your 15GB Google Drive storage)
🔧 Difficulty: Easy - just follow the steps below
1

Open Google Cloud Console

Click the button below to open Google Cloud Console:

Open Google Cloud Console

Make sure you're logged in with: rcmcrecords@gmail.com

2

Create OAuth Client ID

In Google Cloud Console:

  • Click "+ CREATE CREDENTIALS" at the top
  • Select "OAuth client ID"
⚠️ If prompted to configure consent screen:
  • Click "CONFIGURE CONSENT SCREEN"
  • Select "External" → Click "CREATE"
  • App name: RCMC EMR
  • User support email: rcmcrecords@gmail.com
  • Developer contact: rcmcrecords@gmail.com
  • Click "SAVE AND CONTINUE"
  • On Scopes page, add: https://www.googleapis.com/auth/drive.file
  • On Test users page, add: rcmcrecords@gmail.com
  • Click "SAVE AND CONTINUE" until done
  • Go back and create OAuth Client ID again

Configure OAuth Client ID:

  • Application type: Web application
  • Name: RCMC EMR Web Client
  • Authorized JavaScript origins:
    http://localhost:3001
    http://localhost:5173
  • Authorized redirect URIs:
    http://localhost:3001
    http://localhost:5173
  • Click "CREATE"
3

Copy Client ID

After creating, you'll see a popup with your credentials:

  • Copy the Client ID (looks like: xxxxx.apps.googleusercontent.com)
  • Keep this window open - you'll need it in the next step
4

Add Client ID to Project

Option A: Use the batch file (easiest)

  1. Double-click ADD_GOOGLE_CLIENT_ID.bat in the rcmc-emr folder
  2. Paste your Client ID when prompted
  3. Press Enter

Option B: Manual

  1. Open rcmc-emr/.env file
  2. Add this line at the end:
VITE_GOOGLE_CLIENT_ID=your-client-id-here.apps.googleusercontent.com
  1. Replace your-client-id-here with your actual Client ID
  2. Save the file
5

Restart Frontend Server

Open Command Prompt in the rcmc-emr folder and run:

npm run dev

Wait for the server to start, then open: http://localhost:3001

6

Test Lab Results Upload

  1. Login with: admin@rcmc.com / Admin123!
  2. Click "Lab Results" in the sidebar
  3. Click "Upload Lab Result"
  4. Fill in the form and select a PDF file
  5. Click "Upload"
  6. First time only: Google will ask "Allow RCMC EMR to access your Drive?"
  7. Click "Allow"
  8. File uploads to your Google Drive! 🎉
✅ Success! After the first authorization, all future uploads work seamlessly without any prompts.

📋 Setup Checklist

💡 Troubleshooting:
  • "Google Client ID not configured" - Make sure you added it to .env and restarted the server
  • "This app isn't verified" - Click "Advanced" → "Go to RCMC EMR (unsafe)" (it's safe, it's your own app)
  • Upload fails - Check browser console (F12) for errors
