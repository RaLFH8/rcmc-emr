1

Install HTTP SMS App

Time: 3 minutes

  • Open Play Store on your Android phone
  • Search for "HTTP SMS"
  • Install the app (look for one by Avinash Kumar or similar)
  • Open the app after installation
  • Grant SMS permissions when asked
2

Configure HTTP SMS App

Time: 3 minutes

  • In the app, find "Enable Server" or "Start Server" toggle
  • Turn it ON (should be green or blue)
  • Note the IP address and port displayed (e.g., 192.168.1.100:8080)
  • Set a password (optional but recommended)
  • Keep the app running in the background

📝 Write This Down

IP Address: _______________________
Port: _______________________
Password: _______________________

3

Update .env File

Time: 2 minutes

  • Open your project folder: rcmc-emr
  • Find and open the .env file
  • Look for these lines:
VITE_HTTP_SMS_URL=http://192.168.1.100:8080 VITE_HTTP_SMS_PASSWORD=
  • Replace with YOUR phone's IP address and password
  • Save the file

⚠️ Important

Make sure to include http:// at the beginning!
Example: http://192.168.1.100:8080

4

Restart Dev Server

Time: 1 minute

  • Stop the current server (press Ctrl+C in terminal)
  • Start it again:
npm run dev
5

Test SMS Sending

Time: 1 minute

  • Login to RCMC EMR
  • Go to Appointments page
  • Create a test appointment with YOUR mobile number
  • Check if you receive the SMS
  • Verify in HTTP SMS app logs

🎉 Success!

If you received the SMS, your setup is complete!

⚠️ Critical Requirements

✓ Phone and computer MUST be on the SAME WiFi network
✓ HTTP Server must be enabled in the app (toggle ON)
✓ Phone must have load/credit on SIM card
✓ SMS permission must be granted to the app
✓ Keep HTTP SMS app running (don't force close)
