❌ CURRENT ISSUE:
=================
"Invalid JWT: Token must be a short-lived token (60 minutes)"

This error means the Google service account credentials are having
trouble generating valid authentication tokens.

POSSIBLE CAUSES:
================
1. Computer clock is not synchronized
2. Service account credentials file is corrupted
3. Service account key is expired or invalid

SOLUTIONS (Try in order):
=========================

SOLUTION 1: Check System Clock
-------------------------------
1. Right-click on the clock in Windows taskbar
2. Click "Adjust date/time"
3. Turn ON "Set time automatically"
4. Turn ON "Set time zone automatically"
5. Click "Sync now" button
6. Restart the backend server
7. Try uploading again

SOLUTION 2: Regenerate Service Account Key
-------------------------------------------
You need to create a NEW service account key:

1. Go to: https://console.cloud.google.com/iam-admin/serviceaccounts
2. Find your service account (the one you created)
3. Click on it
4. Go to "KEYS" tab
5. Click "ADD KEY" → "Create new key"
6. Choose "JSON"
7. Download the new key file
8. Replace the old google-credentials.json file in rcmc-emr/server/
9. Restart the backend
10. Try uploading again

SOLUTION 3: Verify Service Account Permissions
-----------------------------------------------
Make sure the service account has access to the folder:

1. Go to Google Drive
2. Find the folder (ID: 1JBKtpUdImoQc1LPzyrmVpOsUCYeTky64)
3. Right-click → Share
4. Add the service account email (ends with @*.iam.gserviceaccount.com)
5. Give it "Editor" permission
6. Try uploading again

MOST LIKELY FIX:
================
Solution 1 (sync your computer clock) will probably fix it!

The JWT token error usually happens when your computer's time
is not synchronized with Google's servers.

After syncing your clock, restart the backend and try again.
