🎯 HOW TO USE

Upload Lab Result:
1. Click "Lab Results" in sidebar
2. Click "Upload Lab Result" button
3. Select patient
4. Enter test name (e.g., "Complete Blood Count")
5. Choose test date
6. Select test type
7. Choose PDF file
8. Add notes (optional)
9. Click "Upload"
10. Done! File uploaded to Google Drive ✅

View Lab Result:
1. Find the lab result card
2. Click "View" button
3. PDF opens in new tab
4. View, download, or print

Search & Filter:
1. Use search box for test name or patient
2. Use dropdown to filter by patient
3. Results update instantly

Delete Lab Result:
1. Click trash icon on card
2. Confirm deletion
3. Removed from both database and Drive
