PRODUCTION DEPLOYMENT:
======================
When deploying to production:

1. Add production URL to OAuth settings:
   - Go to Google Cloud Console
   - Add to Authorized JavaScript origins
   - Add to Authorized redirect URIs

2. Add environment variable:
   - VITE_GOOGLE_CLIENT_ID=your-client-id

3. Deploy and test!

TROUBLESHOOTING:
================

"Google Client ID not configured"
→ Add VITE_GOOGLE_CLIENT_ID to .env and restart

"This app isn't verified"
→ Click "Advanced" → "Go to RCMC EMR (unsafe)"
→ Safe to proceed (it's your own app)

"Access blocked"
→ Check authorized origins in Google Cloud Console
→ Make sure they match your current URL

Upload fails
→ Check browser console (F12) for errors
→ Make sure you clicked "Allow" in Google popup
