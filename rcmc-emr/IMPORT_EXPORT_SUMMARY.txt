HOW IT WORKS:
=================================================================

EXPORT:
1. Click "Export" button
2. System generates CSV from all patients
3. File downloads automatically
4. Open in Excel/Google Sheets

IMPORT:
1. Prepare CSV file (use template)
2. Click "Import" button
3. Select CSV file
4. System validates and imports
5. Alert shows results

=================================================================
CSV FORMAT:
=================================================================

COLUMNS (21 total):
1. Patient Number (auto-generated, leave empty)
2. First Name (required)
3. Last Name (required)
4. Date of Birth (YYYY-MM-DD)
5. Age (auto-calculated, leave empty)
6. Gender (Male/Female/Other)
7. Contact Number
8. Email
9. Address
10. Blood Type (A+, A-, B+, B-, AB+, AB-, O+, O-)
11. Allergies
12. Medical History
13. Emergency Contact Name
14. Emergency Contact Number
15. Height (cm)
16. Weight (kg)
17. Blood Pressure (120/80 format)
18. Temperature (°C)
19. Heart Rate (bpm)
20. Respiratory Rate
21. Oxygen Saturation (%)
