📋 CORRECTED BILLING TABLE STRUCTURE

   The billing table uses these columns:
   - id (UUID)
   - patient_id (UUID)
   - bill_date (DATE)
   - items (JSONB)
   - subtotal (NUMERIC)
   - discount (NUMERIC)
   - total_amount (NUMERIC)
   - amount_paid (NUMERIC)
   - balance (NUMERIC)
   - payment_status (TEXT: 'Unpaid', 'Partial', 'Paid')
   - payment_method (TEXT)
   - notes (TEXT)

   Note: No invoice_number column - bills are identified by ID
