🔔 RUN THIS IN SUPABASE - STEP BY STEP
========================================

STEP 1: OPEN SUPABASE
----------------------
1. Go to: https://supabase.com/dashboard
2. Login to your account
3. Select your RCMC EMR project
4. Click "SQL Editor" in the left sidebar

STEP 2: RUN THE SQL SCRIPT
---------------------------
1. Click "New Query" button
2. Copy ALL content from: CREATE_NOTIFICATIONS_TABLE.sql
3. Paste into the SQL Editor
4. Click "RUN" button (or press Ctrl+Enter)
5. Wait for success message ✅

STEP 3: VERIFY TABLE CREATED
-----------------------------
The script will automatically show you:
- Table columns (should show 10 columns)
- RLS policies (should show 4 policies)

If you see results, SUCCESS! ✅

STEP 4: ADD TEST NOTIFICATION
------------------------------
Run this query to get your admin user ID:

SELECT id, email, full_name FROM user_profiles WHERE email = 'admin@rcmc.com';

Copy the "id" value (looks like: d52b2be4-6a2c-4523-baa8-eabe6c22850d)

Then run this (replace YOUR_USER_ID with the ID you copied):

INSERT INTO notifications (user_id, type, title, message, icon, color, link)
VALUES (
  'YOUR_USER_ID_HERE',
  'test',
  'Welcome to Notifications! 🎉',
  'Your notification system is now working perfectly with professional design',
  'Bell',
  'bg-teal-50 text-teal-600',
  '/dashboard'
);

STEP 5: RESTART SERVER
-----------------------
In your terminal:
1. Press Ctrl+C to stop server
2. Run: npm run dev
3. Wait for server to start

STEP 6: TEST IN BROWSER
------------------------
1. Open: http://localhost:3002
2. Login: admin@rcmc.com / Admin123!
3. Look at bell icon (top right)
4. You should see:
   ✨ Gradient hover effect
   🔔 Wiggle animation
   💫 Pulsing red badge with "1"
5. Click the bell icon
6. You should see:
   ✨ Smooth slide-down animation
   🎨 Gradient header

   ⚡ "NEW" badge with pulse
7. Hover over notification:
   ✨ Gradient overlay

TROUBLESHOOTING:
----------------
❌ SQL Error?
→ Make sure you're in the correct project
→ Check if user_profiles table exists
→ Try running script again

❌ No badge showing?
→ Check browser console (F12)
→ Verify user ID in test notification
→ Make sure server restarted

❌ Badge shows but no notification?
→ Refresh the page
→ Check Supabase logs
→ Verify RLS policies created
