🎯 UNDERSTANDING THE TWO SERVERS
================================

YOU NEED BOTH SERVERS RUNNING AT THE SAME TIME!

SERVER 1: FRONTEND (Port 3001)
-------------------------------
✅ This is your WEBSITE
✅ Open in browser: http://localhost:3001
✅ This is where you login and use the EMR system
✅ Start with: npm run dev (in rcmc-emr folder)

SERVER 2: BACKEND (Port 3003)
------------------------------
✅ This is your API SERVER (no website!)
✅ DO NOT open in browser - it's not a website!
✅ This handles file uploads to Google Drive
✅ Start with: STOP_AND_RESTART_BACKEND.bat

WHAT YOU'RE SEEING NOW:
=======================
❌ "Cannot GET /" = You opened http://localhost:3003 in browser
❌ This is WRONG! Port 3003 is not a website!

WHAT TO DO RIGHT NOW:
=====================

1. Make sure FRONTEND is running:
   - Open terminal in rcmc-emr folder
   - Run: npm run dev
   - Wait for: "Local: http://localhost:3001"

2. Make sure BACKEND is running:
   - Double-click: STOP_AND_RESTART_BACKEND.bat
   - Wait for: "🚀 RCMC EMR API Server running on http://localhost:3003"

3. Open your browser to:
   ✅ http://localhost:3001 (FRONTEND - this is the website!)
   ❌ NOT http://localhost:3003 (BACKEND - this is just an API!)

4. Login with: admin@rcmc.com / Admin123!

5. Go to Lab Results page and try uploading

BOTH SERVERS MUST BE RUNNING!
Keep both terminal windows open!
