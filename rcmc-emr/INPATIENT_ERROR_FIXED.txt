========================================
INPATIENT ADMISSION ERROR - FIXED
========================================

ERROR MESSAGE:
"Failed to admit patient: new row for relation "inpatients" violates check constraint "inpatients_status_check""

ROOT CAUSE:
Database constraint mismatch with application values

DATABASE CONSTRAINT (OLD):
- Admitted
- Discharged  
- Transferred

APPLICATION VALUES (CURRENT):
- Stable
- Critical
- Improving
- Observation

========================================
SOLUTION: Run SQL Script
========================================

FILE: FIX_INPATIENTS_STATUS_CONSTRAINT.sql

QUICK FIX (Copy this to Supabase SQL Editor):
---
ALTER TABLE inpatients DROP CONSTRAINT IF EXISTS inpatients_status_check;
ALTER TABLE inpatients ADD CONSTRAINT inpatients_status_check CHECK (status IN ('Stable', 'Critical', 'Improving', 'Observation', 'Discharged'));
---
