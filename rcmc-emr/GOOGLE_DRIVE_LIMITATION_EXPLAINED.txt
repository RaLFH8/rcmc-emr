🔍 GOOGLE DRIVE SERVICE ACCOUNT LIMITATION
==========================================

WHAT WE DISCOVERED:
===================
✅ Folder access works (can read folder, list files, check permissions)
❌ File upload fails (service accounts can't CREATE files in personal Google Drive)

THE ISSUE:
==========
Google Drive has a limitation with service accounts:
- Service accounts can READ from shared folders
- Service accounts CANNOT CREATE files in personal Google Drive folders
- This is a Google security/quota policy

Even though:
- The folder is shared with the service account
- The service account has "Editor" permission
- The API scope is correct ('drive')

Google still blocks file creation with: "Service Accounts do not have storage quota"

GOOGLE'S SUGGESTED SOLUTIONS:
==============================
1. Use Google Workspace Shared Drives (requires paid Google Workspace account)
2. Use OAuth delegation (complex setup, requires domain admin)
3. Use a different storage solution
