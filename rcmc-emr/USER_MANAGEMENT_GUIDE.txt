USER MANAGEMENT - IMPORTANT NOTES
===================================

ISSUE: "User not allowed" Error
--------------------------------
When trying to create new users from the User Management page, you get:
"Error: User not allowed"

WHY THIS HAPPENS:
-----------------
Supabase's auth.admin.createUser() requires SERVICE ROLE KEY, not the 
ANON KEY that's used in the client application. This is a security feature
to prevent unauthorized user creation.

SOLUTIONS:
----------

OPTION 1: Create Users via Supabase Dashboard (RECOMMENDED)
------------------------------------------------------------
1. Go to your Supabase project dashboard
2. Navigate to Authentication > Users
3. Click "Add User" button
4. Enter:
   - Email address
   - Password
   - Confirm email: YES
5. Click "Create User"
6. The user will appear in your EMR system
7. Go to User Management page in EMR
8. Click "Edit" on the new user
9. Set their role (admin, doctor, nurse, receptionist)
10. If doctor role, select which doctor profile

OPTION 2: Create Edge Function (Advanced)
------------------------------------------
Create a Supabase Edge Function that uses SERVICE_ROLE_KEY:

1. Create file: supabase/functions/create-user/index.ts
2. Use SERVICE_ROLE_KEY in the function
3. Call this function from User Management page
4. Requires Supabase CLI and deployment

OPTION 3: Use Service Role Key (NOT RECOMMENDED - Security Risk)
-----------------------------------------------------------------
Replace VITE_SUPABASE_ANON_KEY with SERVICE_ROLE_KEY in .env
⚠️ WARNING: This exposes admin privileges to all users!
⚠️ Only use for development/testing, NEVER in production!

CURRENT WORKAROUND:
-------------------
1. Create users via Supabase Dashboard (Option 1)
2. Use User Management page to:
   - View all users
   - Edit user roles
   - Assign doctors to doctor users
   - Deactivate users (soft delete)

USER ROLES:
-----------
- admin: Full access to all modules
- doctor: Access to patients, consultations, prescriptions
- nurse: Access to patients, appointments, inpatients
- receptionist: Access to appointments, patients, billing

WHAT WORKS IN USER MANAGEMENT:
-------------------------------
✓ View all users
✓ Edit existing users
✓ Change user roles
✓ Assign doctor profiles
✓ Update user information
✗ Create new users (use Supabase Dashboard)
✗ Delete users (can deactivate instead)

RECOMMENDED WORKFLOW:
---------------------
1. Admin creates user in Supabase Dashboard
2. User receives email with login credentials
3. Admin assigns role in User Management page
4. User logs in with assigned role
5. User has access based on their role

FUTURE ENHANCEMENT:
-------------------
To enable user creation from the app:
1. Create Supabase Edge Function
2. Use SERVICE_ROLE_KEY in Edge Function
3. Call Edge Function from User Management
4. This keeps SERVICE_ROLE_KEY secure on server side
