✅ FIX INPATIENTS TABLE - MISSING daily_notes COLUMN

ISSUE:
======
The inpatients table is missing the 'daily_notes' column, causing admission failures.

SOLUTION:
=========
Run the SQL script to create/update the inpatients table with all required columns.

STEPS:
======
1. Go to your Supabase Dashboard
2. Navigate to SQL Editor
3. Open the file: rcmc-emr/ADD_INPATIENTS_TABLE.sql
4. Copy all the SQL code
5. Paste it into the SQL Editor
6. Click "Run" to execute

WHAT THIS DOES:
===============
✓ Creates inpatients table if it doesn't exist
✓ Adds all required columns including daily_notes (JSONB type)
✓ Creates proper indexes for performance
✓ Enables Row Level Security (RLS)
✓ Creates RLS policies for access control
✓ Adds updated_at trigger

COLUMNS INCLUDED:
=================
- id (UUID, primary key)
- patient_id (references patients table)
- doctor_id (references doctors table)
- room_id (references rooms table)
- admission_date (timestamp)
- discharge_date (timestamp, nullable)
- admission_reason (text)
- diagnosis (text, nullable)
- treatment_plan (text, nullable)
- status (Admitted/Discharged/Transferred)
- daily_notes (JSONB array for notes)
- created_at (timestamp)
- updated_at (timestamp)
