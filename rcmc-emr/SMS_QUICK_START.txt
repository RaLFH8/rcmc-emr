  WHAT YOU NEED TO DO NOW:
═══════════════════════════════════════════════════════════

📱 STEP 1: Install HTTP SMS App (2 minutes)
   1. Open Play Store on your Android phone
   2. Search "HTTP SMS"
   3. Install the app
   4. Grant SMS permissions when asked

🔧 STEP 2: Configure the App (2 minutes)
   1. Open HTTP SMS app
   2. Enable "HTTP Server" (toggle ON)
   3. Note the IP address (e.g., 192.168.1.100:8080)
   4. Set a password (optional)

📝 STEP 3: Update .env File (1 minute)
   1. Open: rcmc-emr/.env
   2. Find these lines:
      VITE_HTTP_SMS_URL=http://192.168.1.100:8080
      VITE_HTTP_SMS_PASSWORD=
   
   3. Replace with YOUR phone's IP and password:
      VITE_HTTP_SMS_URL=http://[YOUR_IP]:[PORT]
      VITE_HTTP_SMS_PASSWORD=[YOUR_PASSWORD]

🚀 STEP 4: Restart Dev Server
   1. Stop current server (Ctrl+C)
   2. Run: npm run dev
   3. Done!
